# Лабораторная работа №2: Разработка сканера для языка Haskell

## Название и цель лабораторной работы
**Тема:** Разработка пользовательского интерфейса (GUI) для языкового процессора

**Цель работы:** Разработать приложение – текстовый редактор с графическим интерфейсом, содержащий сканер для распознавания объявлений перечислений на языке Haskell.

## Сведения об авторе
- **Студент:** Еловикова К.С.
- **Группа:** АВТ-313
- **Вариант:** 69 (Распознавание объявлений data в Haskell)

## Постановка задачи
Разработать программу с графическим интерфейсом, которая выполняет следующие функции:
- Редактирование текста (создание, открытие, сохранение файлов)
- Сканирование входного текста и выделение объявлений перечислений на языке Haskell вида:
```data Day = Monday | Tuesday | Wednesday | Thursday | Friday```
- Вывод списка распознанных токенов и обнаруженных ошибок
- Поддержка горячих клавиш и панели инструментов с крупными кнопками

## Вариант задания

**Номер варианта:** 69

**Текстовое описание:** Распознавание объявлений перечислений на языке Haskell. Сканер должен выделять ключевое слово `data`, имя типа (с заглавной буквы), знак равенства `=`, конструкторы (с заглавной буквы) и разделитель `|`. Символ `;` является допустимым.

### Примеры корректных входных строк:

**Пример 1:**
```haskell
data Day = Monday | Tuesday | Wednesday | Thursday | Friday
```
**Пример 2:**

```haskell
data Color = Red | Green | Blue
```
**Пример 3:**

```haskell
data Bool = True | False
```
**Пример 4:**

```haskell
data Day = Monday | Tuesday | Wednesday; data Color = Red | Green | Blue
```
**Пример 5:**

```haskell
data Season = Spring | Summer | Autumn | Winter
data Weekday = Mon | Tue | Wed | Thu | Fri
data Shape = Circle | Rectangle | Triangle
```

## Перечень допустимых лексем:

| Лексема | Описание | Пример | 
|----------|----------|----------|
| `DATA` | Ключевое слово data | `data` |
| `TYPE` | Имя типа (начинается с заглавной буквы) | `Day`, `Color`, `Bool` |
| `EQUALS` | Знак равенства | `=` |
| `CONSTRUCTOR` | Имя конструктора (начинается с заглавной) | `Monday`, `Red`, `True` |
| `PIPE` | Разделитель | `|` |
| `COMMENT` | Комментарий | `-- комментарий` |
| `SEMICOLON` | Разделитель объявлений | `;` |

**Недопустимые символы:**
- @, #, $, %, ^, &, * (специальные символы)
- Цифры в начале имени типа или конструктора
